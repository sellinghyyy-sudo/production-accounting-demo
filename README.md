# Производственный учёт: три участка и экран директора

## Запуск

1. Нужен Python 3.10+.
2. Положите три Excel-файла в папку `import/` (они уже там) и запустите `run.bat`
   (или `pip install -r requirements.txt` и `python -m streamlit run app.py`).
3. Откроется браузер. При первом запуске нажмите «Загрузить из папки import/»
   (или выберите три файла вручную). После этого файлы из папки можно удалить:
   всё хранится в `data/app.db` и работает без них.
4. Тесты логики: `python -m unittest discover -s tests -v`.

## Экраны (меню слева)

- **Заготовка**, **Потребность сварки**, **Документация** - экраны сотрудников. Таблицу можно править
  прямо в ячейках, добавлять и удалять строки, затем «Сохранить изменения». Участки изолированы:
  каждый видит и меняет только свою таблицу.
- **Панель директора** - показатели по всем трём участкам, период, сводная таблица, графики,
  просмотр исходных записей, скачивание отчёта (Excel и CSV).
- **Администрирование** - порог выбросов, правила проверки, сброс данных для повторной демонстрации.

## Как считается

- Выполнение участка = сумма факта / сумма плана за период (не среднее процентов по строкам).
- Единственная настоящая связь между участками - номер партии: сколько нужно сварке по партии
  против того, сколько реально заготовлено по этой партии. У «Документации» общего ключа нет,
  поэтому она считается независимо и ни на что не влияет.
- Проверка записей:
  - красная (в итоги не входит): нет или неверная дата, повтор номера записи (остаётся первая),
    нет или отрицательный план/факт, факт больше плана более чем в 3 раза, у сварки нет или
    отрицательная потребность;
  - жёлтая (в итоги входит, но помечена): нулевой факт при плане, факт без плана,
    нет партии, партия сварки не найдена в заготовке.
- Достоверность показателя: если часть данных исключена или помечена, показатель получает
  отметку «частично». Показатель связки не становится «достоверным», пока по партии нет
  надёжного факта заготовки - даже если ошибка допущена в другом участке.

## Что показать на демонстрации

1. Панель директора, весь период: баннер с найденными ошибками, показатель связки отмечен «частично».
2. Открыть «Заготовка»: строки со статусом 🔴 (P-003 факт 1200, P-004 факт -5, дубль P-005, P-007 без факта).
3. Исправить факт P-003 на 95, сохранить.
4. Вернуться на панель: пересчитались «Заготовка» и связка (партия LOT-03 стала достоверной);
   «Документация» и «Потребность сварки» не изменились - они не зависят от этой правки.
5. Скачать отчёт за период; перезапустить приложение - исправление на месте
   (изменения видны в журнале на экране участка).

## Ограничения

- Нет входа по логинам: разделение по участкам сделано отдельными экранами, а не правами доступа.
- Одна общая база SQLite: рассчитано на одного-двух пользователей одновременно.
